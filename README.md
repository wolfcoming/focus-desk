# Little Fun

个人项目管理桌面应用。Windows 和 macOS 用同一套 Tauri 工程。

## 运行

```bash
npm install
npm run tauri dev
```

安装包：

```bash
npm run tauri build
```

关掉主窗口后，程序留在系统托盘里继续提醒。登录时启动可以在设置里开关（默认关闭）。

数据是本机的一个 SQLite 文件，路径显示在设置页。模型钥匙存在系统凭据里。新库默认是空的；需要示例数据时，到设置页点「加载示例数据」。

## 术语

| 界面 | 含义 |
|------|------|
| 临时任务 | 随手记下、尚未归类的条目 |
| 大项目 / 子任务 | 项目结构；子任务分常规与周期性 |
| 今日三件 | 你当天亲自选的最多三件项目任务 |
| 今天的日常 | 周期性子任务按重复日出现的义务 |
| 等待 | 卡在外部条件上、到点再跟进 |

重要和紧急都由你用四象限标记。系统打断主要看「重要 + 截止/跟进时间」，杂事（不重要但紧急）只出现在今天页，不单独弹窗。

## 第一版包含

- 临时任务、大项目、子任务（常规 / 周期性日常）、今日三件、等待跟进、进度、周回顾
- 进行中的大项目建议不超过 3 个、子任务建议不超过 5 个（软提醒，不强制拦截）
- 系统通知加上置顶小窗：写下当前在做什么，得到继续、先做完这小段，或建议切换
- 模型只在整理临时任务、今日建议、周回顾摘要、等待话术、对上当前在做的事时调用；要不要切换由本地规则判断
