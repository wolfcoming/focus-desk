# Little Fun

个人项目管理桌面应用。Windows 和 macOS 用同一套 Tauri 工程。

## 运行

```bash
npm install
npm run tauri dev
```

安装包：

```bash
npm run tauri build
```

关掉主窗口后，程序留在系统托盘里继续提醒。登录时启动可以在设置里开关。

数据是本机的一个 SQLite 文件，路径显示在设置页。模型钥匙存在系统凭据里，只在整理收集箱、今日三件、对上当前在做的事时调用。要不要切换任务由本地规则判断。

## 第一版包含

- 收集箱、大项目、小项目、下一步、日常义务、等待跟进
- 重要由你判断，紧急由截止和跟进时间计算
- 进行中的大项目最多 3 个，小项目最多 5 个，今日项目重点最多 3 件
- 系统通知加上置顶小窗：写下当前在做什么，得到继续、先做完这小段，或建议切换
